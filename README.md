# sevora-website

SEVORA — AI trading platform website (gold, forex, crypto, indices). Built with React and Vite.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173.

## Build

```bash
npm run build     # output in dist/
npm run preview   # serve the build locally
```

On Windows, `deploy.bat` builds the site and zips `dist/` for upload to Netlify Drop.
